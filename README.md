# Script Scene Link

Godot 4.7 editor plugin. Opening a GDScript from the FileSystem, the script Files panel, or script history opens a scene that script is attached to. Several matches use the scene edited most recently. Selecting a scene in 2D or 3D opens its root script and stays there. Opening a scene file from the FileSystem while on the Script screen opens that root script and stays on Script.

## Install

Copy `addons/script_scene_link` into your project's `addons` folder. Enable **Script Scene Link** under Project > Project Settings > Plugins.
